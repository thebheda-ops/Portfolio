# Portfolio

Frontend portfolio app built with Vite and Preact-compat, plus an Express-ready backend folder.

## Project Structure
- `src/`: frontend source (`.js/.jsx`)
- `backend/`: backend API project
- `dist/`: production frontend build output

## Frontend Stack
- Vite
- Preact (`preact/compat`)
- React Icons
- Tailwind + PostCSS

## Frontend Scripts
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Content Update Path
- Main content data: `src/app/content.js`
